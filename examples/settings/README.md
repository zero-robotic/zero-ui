# 设置与绑定

```sh
cargo run -p settings --locked
cargo run -p settings --no-default-features --features cpu --locked -- cpu
```

滑块和数值输入共用一个字号属性，预览自动跟随。数值输入中的临时文本由控件自己管理，只有合法提交才改变字号。复选框控制可编辑状态；保存按钮可用性来自纯派生状态。后台任务接收设置快照，结果回到 UI 线程后更新保存状态。

示例只保存到内存，不写系统配置。可以把工作闭包替换成业务服务，将 `Result` 作为完成结果处理。后台队列有界，发送失败通过 `PostError` 报告；复杂业务应保存并检查任务句柄。

整个表单是一个独立 `Region`。表单状态变化由框架选择子树更新，不需要应用持有节点 ID。状态、绑定和事件在 `create` 创建一次；视图构建只读取和描述。

`--smoke` 会修改字号、启动后台保存并在约两秒后退出，用于窗口链路验证。
