# 大屏组件展示

```sh
cargo run -p zui-dashboard-example -- cpu
cargo run -p zui-dashboard-example --no-default-features --features gpu -- gpu
```

展示目前实现的全部大屏组件：`DashboardPanel` 科技感切角面板、`MetricCard` 指标卡、`Sparkline` 趋势图，配合传统控件演示联动。数据均为本地模拟数据。

- 每 250 ms 采样一次，指标卡、进度条、趋势图和样本数量同步更新。
- 点击暂停/恢复按钮或操作 Switch，两者共享采样状态，指标卡同时显示状态。
- 拖动 Slider 调整负载偏移（−20%～+20%），立即更新指标、进度和历史曲线；暂停时仍允许手动调整。
- 历史容量为 120，迟到采样用缺测槽表示，不无限补采；遮挡时停止自动采样。
- 窄窗口可滚动查看。Escape 退出，支持 `--smoke-ms 1600` 自动退出。

定时采样和消息协调都在应用层；组件仅接收数据与属性，不引用其他组件实例或窗口后端。测试覆盖暂停、手动调整、恢复后的定时采样和宽窄窗口布局。

此示例展示现有组件，不包含尚未实现的柱状图、饼图、仪表盘或高级发光特效。
