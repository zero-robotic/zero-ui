## 阅读顺序

- 应用开发：平台装配 → 布局 → 控件 → 主题与外观。
- 自定义控件：模块边界 → 核心运行时 → 绘制与文字契约。
- 后端适配：模块边界 → 渲染 → 平台与可移植性。
- 图表与大屏：可选扩展 → 布局和渲染 → 实施计划。

合并不改变 crate 边界：同一专题涉及多个层时，契约、控件实现和平台适配仍遵守各自模块职责。
