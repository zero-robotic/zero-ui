# 按需动画与光标闪烁

已提供与系统时钟无关的控件动画契约，并接通桌面调度与单行输入光标。动画只在需要时请求未来期限，不默认启动持续帧循环。

## 分层与时间语义

`Widget::animate(elapsed)` 接收应用传入的单调经过时间，返回 `AnimationUpdate { invalidation, next_frame }`。next_frame 是同一时间轴上的绝对期限，必须严格晚于 elapsed；None 撤销本控件的请求。控件负责计算状态和失效范围，不创建线程、计时器或调用系统时钟，也不在此回调发起业务 I/O。

`Tree::advance_animations` 遍历当前节点并合并失效与最早期限。移除节点后不再访问其动画状态；非未来期限返回 InvalidAnimationDeadline，避免立即唤醒形成忙循环。此操作不要求已提交布局，但动画回调不应读取未提供的几何。布局失效仍须在绘制前重新准备。回调发生错误时不承诺所有控件状态回滚，调用方不得继续把失败帧当成成功结果呈现。

初期每次推进扫描当前节点，复杂度为 O(节点数)，不包含独立的活跃动画索引。上层使用单调时间；同一时刻重复调用应保持状态一致。错过多个期限时直接计算当前状态，不循环补绘所有遗漏帧。

WidgetHost 在事件处理和绘制阶段推进状态，通过 Application::animation_deadline 发布期限。Driver 分别保存应用定时器、动画期限与 GPU 重试期限，只向平台提交最早项。动画到期调用 Application::animate，不向应用模型发送业务 Wake；同一时刻多个来源到期，各自处理，不吞掉后续期限。动画的取消和延期不影响其他来源。

隐藏窗口不推进动画，驱动撤销其动画期限；恢复后按当前时间计算。平台底层采用合并期限的既有语义，取消或延期后可能收到一次旧的唤醒，驱动检查各来源的当前期限并忽略它，不触发业务事件或重绘循环。断开连接清除 Host 和驱动的动画调度状态。

## 输入光标

TextInputView 的 caret_blink_interval 默认 500 ms，表示亮/暗各阶段的长度，完整周期为 1 秒；None 表示常亮，零时长是非法样式。当前不读取操作系统光标闪烁偏好，调用方可显式配置常亮。

聚焦、可编辑且只有插入点时请求闪烁；选区、只读、禁用、失焦和非空预编辑期间不请求闪烁。预编辑光标的显示继续遵守 IME cursor 规则。有效按键、选择变化和组合输入变化会立即恢复光标可见，并从下一次时间推进重新计时。

光标隐藏只影响绘制，不改变排版、选择、横向滚动、IME 候选位置或会话代次。相位计算使用整数时间，延迟帧直接跳到当前相位；时间到达 Duration 表示上限时停止请求无法表示的未来期限。

独立 Tree 使用者需调用 advance_animations 并安排返回的期限；不推进时间时光标保持可见，方便确定性离屏输出。WidgetHost 已完成这一装配。

## 验证范围

测试覆盖节点期限合并与移除、非法期限、时间跳跃与重置、三种唤醒来源的独立性、隐藏窗口取消，以及真实输入框和 Host 的期限衔接。CPU 像素测试验证亮/暗画面差异、输入后恢复、无重排与候选位置稳定。

当前没有动画曲线、属性插值库、布局过渡编排或大屏特效组件；上述能力可复用此调度契约继续建设。本阶段未进行真实桌面闪烁与系统节能行为验收，也未重跑 GPU 绘制测试。
