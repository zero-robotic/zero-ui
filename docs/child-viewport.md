# 子内容视口与坐标一致性

`Widget::child_viewport(PaintContext) -> ChildViewport` 是子内容呈现的公共契约，为滚动容器和自定义可平移内容提供基础。核心只读取平移和裁剪值，不感知 ScrollView 或具体控件。布局服务、绘制适配器和平台后端均不需要识别滚动类型。

## 契约

`translation` 是相对于容器本地坐标的子内容平移，默认零；向下查看内容通常使用负 y。`clip` 是可选的固定矩形，坐标相对于容器边框盒，在平移子内容之前应用。默认不额外裁剪。两者只作用于后代，不改变容器自身的绘制、命中区域或布局结果。

```rust
fn child_viewport(&self, context: PaintContext) -> ChildViewport {
    ChildViewport {
        translation: Point::new(-self.offset.x, -self.offset.y),
        clip: Some(context.content_bounds),
    }
}
```

上例只是 Widget 方法示意，offset 的范围管理属于控件自身。查询必须是纯函数；状态变化至少请求 Paint 失效，不需要仅为平移重新测量。内容尺寸或视口尺寸变化仍要按正常规则请求 Layout。`Tree::layout_box` 始终返回布局坐标，不返回滚动后的屏幕坐标。

已有 `View::clipped(true)` 仍裁剪节点自身与全部后代，子视口裁剪则仅裁剪后代。两种裁剪可以叠加。子视口不会改变焦点所有权、指针捕获或 Tab 顺序；被裁掉的已捕获控件仍接收按正确局部坐标转换的事件。

## 一次操作使用一致的坐标

核心在构建场景、命中查询和输入分发前建立呈现坐标快照，验证平移、矩形及祖先累加后的坐标。非法值返回 `InvalidChildViewport`，不会发布半个场景或继续分发该次输入。

- 绘制：先画容器自身，再在固定裁剪范围内平移并画后代。
- 命中：反向遍历绘制顺序，使用相同祖先平移与裁剪。
- 输入：从同一次快照计算捕获、目标和冒泡接收者的局部坐标；回调中改变平移在下一次操作生效。
- IME：候选框从焦点控件局部空间转换到窗口空间，并与祖先边框裁剪和子视口裁剪相交；完全不可见或零面积裁剪返回 None。

节点自己的子视口不能裁剪它自己的 IME 区域。嵌套视口逐级累加平移，裁剪留在各自容器坐标中，不跟随内容平移。

当前快照遍历全部节点并保存 BTreeMap，时间开销为 O(N log N)，额外空间为 O(N)。此实现优先保证各坐标消费者一致；大规模列表还需要结合虚拟化与失效规则评估缓存。当前没有将它宣称为大列表性能优化。

## 验证与后续

核心测试覆盖嵌套平移、静止裁剪、命中、捕获坐标、IME 裁剪、零面积视口、非法输入恢复和布局不变。顶层渲染测试用仅依赖公共契约的自定义视口，逐像素检查 CPU/GPU 在三种偏移及 1×/2× 缩放下的绘制与命中一致性。

该契约是通用基础。纵向内容测量、范围管理、滚轮/键盘和边界冒泡已由 [ScrollView](scroll.md) 接入；覆盖式滚动条已通过通用前景接口接入；焦点切换后的区域滚入已接入；横向/双向已接入；触摸惯性和虚拟化仍需后续实现。内容高度由实际布局计算。


前景能力通过 Widget::paint_foreground 与 hit_test_foreground 表达，顺序是自身绘制、后代、前景；命中反向执行。前景与自身绘制使用相同本地坐标，不跟随子内容平移，也不受自身 child_viewport.clip 限制，但仍遵守节点和祖先裁剪。默认前景不绘制、不命中，既有控件行为保持不变。核心专项测试验证该顺序及裁剪边界。
